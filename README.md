# LabelPress

Label Press is a label designer for thermal printers, packed into one self-contained HTML file. Open it in a browser and it runs offline, with no install, build step or external dependencies.

Food labels. It builds FDA-style Nutrition Facts panels in standard, simplified, tabular and linear formats, with FDA rounding rules. It also handles ingredient and allergen statements, and lot codes and expiry dates calculated from the pack date.

Shelf labels. Batch mode prints one label per row of pasted data. A one-click shelf layout puts the location code in large type with an up or down arrow and a matching barcode.

Images. You can add logos, certification marks and line art. They’re converted to crisp black and white for the print head, with a preview of exactly what will print.

Flexibility. Labels can be 1″ to 6″ at 152, 203, 300 or 600 dpi, in any orientation or rotation. Items stack automatically, or you can drag, resize and position each one freely. You can add as many custom text fields as you need, and barcodes come in UPC-A, EAN-13, Code 128 and Code 39.

Printing. Labels are sent as native ZPL, so text and barcodes stay sharp. They go directly to a Zebra printer by IP address, or through PrintNode, or through the browser’s print dialog. An optional Labelary preview shows the ZPL as the printer will render it.

Import and export. Designs are saved in your browser. You can export a single label, your whole library, or your library plus your printer setup as JSON, and import them on another machine. Your PrintNode API key is never included in an export.
