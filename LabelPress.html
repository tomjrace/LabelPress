Imagenone
PNG, JPEG, GIF, WebP, BMP or SVG. A plain black-on-white logo prints best on thermal stock.
Do not put a Nutrition Facts panel here. A scanned or screenshotted panel arrives as a bitmap, and a thermal head prints one dot or no dot with nothing in between, so fine type breaks up into something between ugly and unreadable. An illegible panel is a labelling problem, not just a cosmetic one. Build it in the Nutrition Facts section instead, where it prints as real printer text at the full resolution of the head. The same goes for ingredient statements, allergen warnings and any other small print. Keep images for logos, certification marks and simple line art.
Width is taken literally, so an image can now be wider than the column it sits in and will simply run off the label edge. For an image-only label, set Columns to “Single column” in Arrangement, or use free placement, then press Size to the label.
Thermal conversion
A thermal head prints one dot or no dot, so the image is reduced to pure black and white before it is sent. These settings control that, and apply when sending ZPL to a printer.

Arrow on each label
Both prints every row twice — once pointing up for the bottom of the shelf, once pointing down for the top. Size, shape and position live in the Arrow section.
What the rows feed
These feed the ordinary Title and Barcode blocks, so each stays a separate item in the stacking order and can be dragged and resized in the preview. Their own size, alignment and position settings still live in their own sections.
Preview
The preview shows one label at a time so you can check the layout against real data.
Output
Print every label sends the whole run to the browser dialog, one label per page. Send every label pushes the run to the printer chosen in Printers as one ZPL stream.
Arrangement
Item to move
Drag items directly in the preview, or select one and use the arrow keys. Hold Shift while dragging to move in a straight line. The selected item gets eight handles: drag a corner to scale the whole thing — type, bars, artwork — or a side to change only the box, which is what makes text wrap where you want it.
Width 0 lets the item shrink to fit its own content. Pinning to the right or bottom edge keeps an item in place when you change label size.
Stacking order
    Printersnone
    Media
    Leave this alone unless you mean it. On a Zebra, the media command (^MTD / ^MTT) is a persistent setting, not a per-label one. Choosing Force here rewrites the printer’s own configuration on every job, and it stays that way after the job finishes. Set the media type at the printer and leave this on “as it is set” unless you are deliberately driving one printer two different ways.
    Registration
    If the whole design lands off the die, print the test label, measure how far the corner marks are from the real corners, and put those figures here. Untick the label length to let the printer use its own gap detection instead, which is usually right once the media is calibrated.
    Font matching
    The printer’s own font is not metrically identical to the Helvetica on screen. Print a test label, compare it with the preview, and nudge these until they agree. 1.00 means the point size is sent straight through.
    Darkness and speed of 0 leave the printer on its own settings.
    The ZPL is rebuilt from the design and uses the printer’s own scalable font, so characters stay text. Always run one test label before a production run — ZPL font metrics are close to, but not identical to, the on-screen Helvetica.
    Import / export
    Export one label saves the design on screen. Export all labels saves every design held in this browser. Export all adds your printer list on top — that is the one to hand someone who needs the whole setup. Import label(s) accepts any of the three, and several files at once.
    Images are never exported. Position, size and conversion settings travel with the design, but the picture itself does not — whoever opens the file picks their own copy of it. Your PrintNode API key is never written into an export either.
